# claude-cleanup

`~/.claude` 以下の履歴類を削除する。削除は取り消せないので、
**必ず一覧を見せてユーザーの確認を取ってから**消す。

## 手順

1. 一覧を表示する(この段階では何も消えない):

   ```sh
   sh ~/.claude/skills/claude-cleanup/scripts/cleanup.sh
   ```

2. 出力をそのままユーザーに示し、次を添えて削除してよいか確認する:
   - 会話履歴が消えると `/resume` で過去のセッションを開けなくなる
   - 編集前バックアップが消えると、過去セッションの編集を巻き戻せなくなる

3. 承認されたら削除する:

   ```sh
   sh ~/.claude/skills/claude-cleanup/scripts/cleanup.sh --yes
   ```

4. 何件・どれだけ消えたかを報告する。

## 消すもの・消さないもの

| 消す | 消さない |
|---|---|
| `projects/*/` の会話記録(`*.jsonl` とセッションIDのディレクトリ) | `projects/*/memory/`(会話をまたぐメモ) |
| `history.jsonl`(入力履歴) | `settings.json`、`.credentials.json`(ログイン情報) |
| `file-history/`、`plans/`、`shell-snapshots/`、`todos/` の中身 | `skills/`、`plugins/`、その他すべて |

対象はスクリプトに列挙したものだけで、それ以外には触れない。
ユーザーが `memory/` や設定まで消したいと言った場合は、スクリプトを
書き換えずに個別にコマンドを提示して確認を取る(ログイン情報を消すと
再ログインが必要になる、など影響を説明する)。

## 実行中のセッションについて

直近 60 分以内に更新されたものは対象から外れる。今の会話の記録や、
別ウィンドウで動いているセッションを壊さないため。それも含めて消したい
場合は、そのセッションを終了してから `ACTIVE_MINUTES=0` を付けて実行する。

## 自動削除との関係

Claude Code は `settings.json` の `cleanupPeriodDays`(既定30日)より古い
会話を起動時に自動で消している。定期的に消したいだけならそちらの値を
小さくするよう案内する。このスキルは「今すぐ全部消したい」ときのもの。
