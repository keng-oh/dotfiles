# シェルスクリプトの規約

- 特に理由が無ければ **POSIX sh**(`#!/bin/sh`)で書く。bash 固有の機能
  (配列、`[[ ]]`、`local` 以外の拡張、`<<<` など)を使うなら `#!/usr/bin/env bash` にする
- 冒頭で `set -eu`。パイプの失敗も拾いたいなら bash にして `set -euo pipefail`
- 変数展開は必ずダブルクォートで囲む(`"$var"`)
- 外部コマンドは `command -v <cmd> >/dev/null` で有無を確かめてから使う。
  OS 固有のコマンド(`pacman` / `apt` / `systemctl` など)を前提にしない
- 何度実行しても安全(冪等)に書く。既にある状態なら何もせずに終わる
- 破壊的な操作(削除・上書き)は、対象を表示して確認を取る形にするか、
  `--yes` のような明示的なフラグを要求する
- エラーは標準エラー出力に、何が足りないか・どうすればよいかが分かる文で出す
- 書いたら `sh -n`(構文チェック)を実行する。`shellcheck` があればそれも使う
